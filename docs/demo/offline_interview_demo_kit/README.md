# Offline Portfolio Demo Kit

This folder is the Day48 offline portfolio demo kit for Network Automation Lab.

Open this file first during a portfolio review or offline demo. It tells you which documents to show, which local commands are safe, and how to explain the project if GitHub, internet access, routers, switches, VPN, WireGuard peers, iperf3 endpoints, or lab devices are unavailable.

## What To Open First

Recommended open order:

1. `README.md` in this folder.
2. `demo_checklist.md`.
3. `demo_commands.md`.
4. `interview_talk_track_3_to_5_min.md`.
5. `troubleshooting_guide.md` if anything in the local environment is missing.
6. `no_live_dependency_statement.md` when you need to state the safety boundary clearly.

## Offline Demo Boundary

The portfolio demo can run without:

- GitHub.
- Internet access.
- Router or switch access.
- VPN or WireGuard access.
- Live lab devices.
- SSH.
- Device configuration changes.

The demo is based on committed source code, committed documentation, local tests, local report-index generation, local dashboard routes, and existing evidence references.
