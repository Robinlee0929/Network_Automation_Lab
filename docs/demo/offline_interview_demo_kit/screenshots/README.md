# Optional Screenshot Backup Assets

This folder is reserved for optional offline backup screenshots.

Actual screenshot binary files are not required for Day48 unless they already exist. The offline interview demo should remain usable from committed source code, documentation, local tests, local report-index behavior, and local dashboard routes.

Suggested screenshot names:

- `dashboard_home.png`
- `reports_index.png`
- `latest_lab_overview.png`
- `day47_runbook.png`
- `demo_command_output.png`

Screenshots are useful when an interview browser cannot open a local page, dependencies are missing, or the interview site has no internet. They are backup presentation assets, not required evidence.
