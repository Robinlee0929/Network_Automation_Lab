# v0.2 Artifact Checklist

Day41 uses this checklist to package v0.2 artifacts without running live tests, opening SSH, changing devices, implementing voice/AI features, or creating a `v0.2` tag.

## Required Artifacts

| Artifact | Path or surface | Status | Notes |
| --- | --- | --- | --- |
| README v0.2 summary | `README.md` | Required | Must link to the release package and state that Day41 prepares the package while Day42 owns the tag. |
| Release package | `docs/releases/v0.2_release_package.md` | Required | Canonical Day31-Day40 package summary. |
| Artifact checklist | `docs/releases/v0.2_artifact_checklist.md` | Required | This checklist. |
| Demo handoff guide | `docs/portfolio/v0.2_demo_handoff_guide.md` | Required | Portfolio demo order and safety-level talk track. |
| Runner task catalog | `network_lab.py` | Required | Day41 task must be report-only and non-live. |
| Safety metadata | `network_lab.py` and tests | Required | Day41 must require no live device and no password. |
| Tests | `tests/test_network_lab_task_catalog.py`, `tests/test_network_lab_runner.py` | Required | Tests should cover catalog metadata, docs, no SSH/live behavior, and report generation. |

## Optional Artifacts

| Artifact | Path or surface | Status | Notes |
| --- | --- | --- | --- |
| Day31-Day40 generated evidence | `reports/lab-summary/`, `reports/portfolio/` | Optional | Local evidence may be regenerated during review, but Day41 does not require live behavior. |
| Dashboard `/reports` view | Local dashboard | Optional | Useful for demo, but not required for the documentation package commit. |
| Latest lab overview | `reports/lab-summary/latest_lab_overview.*` | Optional | Generated local report and may be absent. |
| Report index | `reports/report_index.html` | Optional | Generated local HTML index and may be absent until regenerated. |
| Day41 generated report | `reports/portfolio/day41_v0.2_release_packaging.*` | Optional generated | Created by the report-only runner task and ignored by `.gitignore`. |

## Generated Artifacts Ignored by `.gitignore`

The repository ignores `reports/`. This is intentional.

| Generated artifact | Git status expectation | Notes |
| --- | --- | --- |
| `reports/portfolio/day41_v0.2_release_packaging.json` | Ignored | Report-only local output. |
| `reports/portfolio/day41_v0.2_release_packaging.html` | Ignored | Report-only local output. |
| Other `reports/**/*.json` or `reports/**/*.html` files | Ignored | Local evidence and dashboard/report-index outputs. |

## Deferred to Day42

| Item | Reason |
| --- | --- |
| `v0.2` git tag | Day41 packages release readiness only. Tagging is reserved for Day42. |
| Final release note tied to the tag | Should be created or finalized with the Day42 tag step. |
| Post-tag verification | Must happen after the actual Day42 tag. |

## Deferred to v3.0

| Item | Reason |
| --- | --- |
| Voice + AI Network Test Assistant | Roadmap-only. Not implemented in v0.2. |
| AI-assisted Network Test Orchestration | Roadmap-only. Requires separate design, safety review, and implementation. |
| AI report assistant features | Roadmap-only. Day41 only documents the future direction. |

## Known Limitations

- Some optional reports may be missing.
- Generated reports under `reports/` may be ignored by `.gitignore`.
- Day41 does not create a `v0.2` tag.
- Day41 does not prove new live behavior.
- Day41 only packages existing Day31-Day40 evidence.
- Voice + AI is future roadmap only, not implemented in v0.2.
