# v0.1 Release Notes

## Release Summary

Network Automation Lab v0.1 packages the Day1-Day26 lab automation work into a portfolio-ready release. The release focuses on repeatable network validation, safety-labelled runner workflows, readable JSON/HTML evidence, and a clear reviewer path.

## Included Scope

- MikroTik RouterOS baseline, reset setup, post-setup, multi-device baseline, WireGuard validation, and performance workflows.
- Cisco IOS switch topology validation.
- Lab-level topology and report summaries.
- Local Flask dashboard for report viewing and safe allowlisted command examples.
- Unified runner task catalog with report-only, read-only, guarded-live, dry-run, and disabled safety boundaries.
- Portfolio evidence index, RC demo flow, Day25 RC validation evidence, and Day26 v0.1 documentation polish.

## Safety Posture

The v0.1 Day26 package is documentation-only. It adds release notes and a concise portfolio checklist; it does not add runner tasks, product features, report generators, live workflow execution, or generated release package artifacts.

Live validation remains behind the existing read-only, dry-run, guarded-live, or disabled runner controls. Day26 documentation does not read `config.json`, exported WireGuard `.conf` files, SSH passwords, private keys, or local secrets.
