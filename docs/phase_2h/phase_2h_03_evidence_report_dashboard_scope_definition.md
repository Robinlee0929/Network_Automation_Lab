## Future Dashboard Boundary

Any future dashboard must be treated as a passive evidence/report viewer.

It must not:

- trigger jobs
- collect evidence
- run commands
- invoke runners, adapters, brokers, or execution paths
- access live devices
- use SSH
- use NETCONF
- use RESTCONF
- call providers, APIs, or models
- consume secrets or credentials
- modify configuration
- perform config backup
- perform config change
- create a queue, scheduler, worker, broker, or agent loop
- add production execution behavior
